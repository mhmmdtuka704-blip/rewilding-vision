# Public visual assets

`canopy.svg` is a decorative code-generated illustration. It is not a satellite image, field result or dataset annotation.

The local internship version used a company logo and a RUGD photograph in its header. Those binary assets are not redistributed here. The app retains a typographic tOD acknowledgment and can display an optional locally supplied `tod-logo.png` when the user has appropriate rights; that file is ignored by Git.
