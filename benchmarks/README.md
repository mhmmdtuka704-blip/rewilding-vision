# Recorded experimental evidence

These JSON files preserve the **25 October 2026** measured run. They are not new benchmark measurements made when the GitHub repository is published.

| File | Evidence |
|---|---|
| `test_metrics.json` | Final 48-image test counts, metrics and per-image errors |
| `darkening_metrics.json` | Fixed 12-image synthetic brightness ×0.65 check |
| `training_history.json` | Five actual training/validation epoch records |
| `training_summary.json` | Frozen baseline, deployment gate, settings and runtime |
| `alignment_controls.json` | Known-motion recovery and residual apparent change |

Raw images, user uploads and fabricated geographic coordinates are not published here. See the dataset manifest for acquisition and the [results explanation](../docs/results.md) for the boundaries of each claim.
